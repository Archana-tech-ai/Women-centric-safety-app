Women-Centric Safety App
Overview

Women-Centric Safety App is an Android-based application designed to provide quick and reliable emergency assistance using voice commands, real-time location tracking, and multi-contact alert systems. The app focuses on enhancing women’s safety by enabling fast communication between users, neighbors, and police authorities.

Features
Voice-based emergency activation (secret command)
Panic button for instant alerts
Real-time GPS location tracking
Multi-contact alert system (family, neighbors, police)
Complaint reporting with images and location
Identification of unsafe areas
Push notifications using Firebase
Role-based access (User, Neighbor, Police)

Technologies Used
Frontend: Android (Java, XML)
Backend: Firebase Realtime Database
Authentication: Firebase Authentication
APIs:
Google Maps API
Speech-to-Text (STT) API
Services:
GPS / Geo-location
Firebase Cloud Messaging (FCM)
Security: Hash-based encryption

Modules
1. User Module
Register and login
Trigger emergency alerts
Share live location
Report complaints with images
2. Neighbor Module
Receive emergency alerts
View nearby incidents
Stay informed about local safety
3. Police Module
Register and login
Verify complaints
Monitor and respond to incidents

How It Works
User logs into the application
Emergency triggered via voice command or panic button
App captures live location
Alerts sent to contacts, neighbors, and police
Authorities verify and take action
Installation
Clone the repository
Open the project in Android Studio
Connect Firebase to the project
Add Google Maps API key
Build and run the application
Future Enhancements
AI-based threat detection
Integration with wearable devices
Offline alert functionality
Enhanced data security
Conclusion

Women-Centric Safety App provides a smart and efficient solution for women’s safety by combining voice technology, real-time tracking, and community-based support to ensure quick emergency response.
